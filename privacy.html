개인정보처리방침

시행일: 2026년 11월 10일 | 앱 이름: moin-backend (무인채널 백본)

1. 개요

'무인채널 백본'은 유튜브 채널 소유자 류정빈(jeongbinlyu230@gmail.com)이 자신의 채널을 자동 운영하기 위해 사용하는 개인 소프트웨어입니다. 본 앱은 채널 소유자 본인의 Google 계정으로만 승인되어 사용되며, 일반 대중을 대상으로 하는 서비스가 아닙니다.

2. 수집·이용하는 정보

  • Google OAuth 인증 토큰: YouTube Data API 및 YouTube Analytics API 접근에 필요한 토큰. 소유자의 개인 PC에만 저장되며(token.json), 어떤 외부 서버로도 전송되지 않습니다.
  • 유튜브 채널 정보: 채널명, 채널 ID, 구독자 수, 조회수, 영상 수 등 공개 통계.
  • 영상 관련 정보: 본인 채널에 업로드한 영상의 제목, 설명, 태그, 업로드 상태.

3. 이용 목적

  • 본인 유튜브 채널의 영상 자동 업로드 및 예약
  • 채널 성과(조회수, 시청시간 등) 분석 및 기록
  • 댓글 확인 및 관리

4. 제3자 제공

어떠한 경우에도 제3자에게 데이터를 제공·판매·공유하지 않습니다.

5. 보관 및 파기

인증 토큰은 소유자 PC의 로컬 파일에 보관되며, 파일 삭제 시 즉시 파기됩니다. Google 계정 승인은 언제든 Google 계정 - 앱 권한에서 철회할 수 있습니다.
